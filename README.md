# trincheras-de-sangre
Frente occidental, 1918. Tu helicóptero es derribado sobre Verdún y quedás atrapado entre trincheras enemigas. Junto a un escuadrón con nombre, miedos y cartas sin enviar, sobrevivís a cinco misiones y a oleadas cada vez más duras. Tus decisiones en el campamento cambian el final: no todos volverán a casa, pero todos prometieron intentarlo. )
